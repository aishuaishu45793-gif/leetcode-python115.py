# Python Practice Projects 🐍

## About This Repository

This repository contains my Python programming practice projects. I created these programs to improve my problem-solving skills, understand Python concepts, and develop logical thinking.

Each program focuses on a different basic programming concept using Python.

## Projects Included

### String Programs
- Reverse a String
- Character Counter
- Find the Largest Digit
- Remove Spaces from a String
- Count Vowels in a String
- Check Palindrome String
- Count Words in a Sentence

### Number Programs
- Sum of Digits
- Simple Interest Calculator
- Power Calculator
- Strong Number Checker
- Armstrong Number Checker
- Calculate Factorial of a Number

### List Programs
- Find Prime Numbers in a List
- Find Common Elements in Two Lists
- Find the Smallest Number in a List
- Find the Largest Number in a List
- Remove Duplicate Elements from a List
- Count Even and Odd Numbers
- Calculate Average of List Elements

## Technologies Used

- Python
- Visual Studio Code
- Git
- GitHub

## How to Run the Programs

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the Python file you want to execute.
5. Run the program using the terminal.

Example:

```bash
python filename.py
```
